# Academic Research

Trimmed fork of [google/adk-samples](https://github.com/google/adk-samples) at
`4fddcec` (`python/agents/academic-research`, Apache 2.0 — see `LICENSE`), kept
as a target for the `porting-to-ventis` skill.

The source tree under `academic_research/` is unmodified. See
[Provenance](#provenance) for what was removed.

## Overview

An agent that explores the academic landscape around a seminal paper. Given the
paper as input, it analyzes the core contributions of the work, then:

1. Uses a sub-agent to find, via Google Search, recent publications that cite
   the seminal paper — mapping its contemporary influence.
2. Synthesizes the original analysis with those recent citing papers to propose
   future research directions.

## Agent details

| Feature | Description |
| --- | --- |
| **Framework** | Google ADK (`google-adk`) |
| **Interaction type** | Conversational |
| **Agent type** | Multi agent |
| **Components** | Tools: built-in Google Search |
| **Model** | `gemini-2.5-pro` via Vertex AI |

### Architecture

<img src="academic-research.svg" alt="academic researcher" width="800"/>

An `LlmAgent` coordinator with two sub-agents wrapped as `AgentTool`s:

```
academic_research/
├── agent.py                    academic_coordinator (= root_agent)
├── prompt.py                   ACADEMIC_COORDINATOR_PROMPT
└── sub_agents/
    ├── academic_websearch/     finds recent citing papers (google_search tool)
    └── academic_newresearch/   proposes new research directions
```

`__init__.py` resolves the GCP project with `google.auth.default()` at import
time and defaults `GOOGLE_CLOUD_*` / `GOOGLE_GENAI_USE_VERTEXAI` in the
environment, so importing the package requires application default credentials.

## Prerequisites

* Python 3.10–3.12
* [uv](https://docs.astral.sh/uv/getting-started/installation/)
* A Google Cloud project with Vertex AI enabled
* [`gcloud`](https://cloud.google.com/sdk/docs/install)

## Setup

```bash
uv sync
cp .env.example .env      # fill in your project id, location and bucket
```

Authenticate:

```bash
gcloud auth application-default login
gcloud auth application-default set-quota-project $GOOGLE_CLOUD_PROJECT
```

## Running the agent

```bash
uv run adk run academic_research     # terminal
uv run adk web                       # local web UI, pick academic_research
```

Try `who are you`, then supply a paper (title, DOI, URL, or a PDF in the web
UI). The upstream
[README](https://github.com/google/adk-samples/tree/main/python/agents/academic-research)
has a full example transcript.

## Provenance

Reduced to what a port needs — the three agents plus the prompts they import.
Removed from upstream:

| Removed | Why |
| --- | --- |
| `deployment/` | Vertex AI Agent Engine deploy and smoke-test scripts |
| `eval/`, `tests/` | evaluation set and pytest suite |
| `uv.lock` | regenerated by `uv sync`; ignored by this repo |
| `pyproject.toml` dev/deployment groups, `[tool.*]` config | test, lint and type-check tooling, plus a `ruff` `extend` pointing outside the fork |

`pyproject.toml` dependencies were narrowed to what the remaining source
actually imports: `google-adk`, `google-auth`, `python-dotenv`.
